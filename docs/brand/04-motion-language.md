# Motion Language

Motion explains cause, direction, hierarchy, progress and connection.

| Asset | Purpose | Duration | Trigger / loop | Reduced-motion fallback | Constraint |
|---|---|---:|---|---|---|
| Flow Mark reveal | Introduce one-to-many flow | 800 ms | Entry, once | Complete mark | SVG/CSS only |
| Brief-to-system hero | Explain the product | 8–14 s | Viewport, calm loop | Static final constellation | No blocked content |
| Brand inheritance | Show shared context | 2–4 s | Section entry | Connected static labels | No colour-only meaning |
| Channel branching | Show direction | 1.2 s | Section entry | Visible paths | No particles |
| Card generation | Show structured output | 2–5 s | Hero loop | Populated cards | Six cards maximum |
| Calendar population | Explain planning | 3–6 s | Future authentic clip | Poster | Lazy media |
| Version transition | Explain retained history | 400 ms | User control | Instant state | No destructive illusion |
| Export completion | Confirm completion | 220 ms | Product action | Static confirmation | Product only |
| Ambient path | Add depth | 10–14 s | Hero only | Disabled | No pointer chasing |

Primary easing is `cubic-bezier(0.22, 1, 0.36, 1)`. Micro interactions use 120–180 ms; standard transitions 220–320 ms. `prefers-reduced-motion` disables loops and leaves the final understandable state.
