# Media Production Plan

## Initial state

The site ships with SVG brand assets, a CSS Content Constellation, reusable browser frames and an Open Graph card. No fabricated screenshots or stock testimonials are used.

## Production sequence

1. Stabilise representative demo data.
2. Capture the canonical Brief → Brand Profile → module workflow at 1440 px.
3. Record clean cursor paths without sensitive content.
4. Edit 8–16 second feature clips and a 20–30 second hero sequence.
5. Export WebM and MP4, then create accurate poster images.
6. Test captions/adjacent descriptions, Save-Data, lazy loading and reduced motion.

Media uses the fictional **Northstar Roasters** capture project and excludes
customer data, tokens and provider identifiers. Deterministic setup,
storyboards, stills and status live under [`docs/media`](../media/01-product-demo-project.md).
No final video is encoded.
