# Northstar Roasters Product Demonstration

Northstar Roasters is a fictional specialty-coffee brand created exclusively for Web Content Flow product capture. It is not a customer, operating company, trademark claim, or performance case study.

## Fixed brief

- Industry: specialty coffee
- Model: independent direct-to-consumer brand
- Audience: design-conscious customers who choose and brew coffee at home
- Campaign: fictional seasonal coffee collection
- Objective: introduce the collection and encourage visitors to explore it
- Tone: warm, confident, precise, modern
- Values: craft, clarity, quality, considered design
- Output language: English
- Fixed reference date: 2026-01-01

## Workflow coverage

The capture fixture normalises the existing deterministic full-module seed into Northstar Roasters content. It includes Brief, Brand Profile, Website, Social, Ads, Video, General Copy, Calendar, Library, versions and Export-compatible content.

No real identity, customer email, protected third-party branding, revenue claim, API token or production provider is used.

`capture@webcontentflow.local` is synthetic. Its development-only password is inherited from the documented demo fixture. The account is created directly by the guarded seed; capture mode does not bypass authentication.
