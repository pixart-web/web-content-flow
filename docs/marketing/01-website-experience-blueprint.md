# Website Experience Blueprint

## Objective

Explain the content operations category and the one-Brief-to-system transformation in the first viewport, then earn private-beta interest without fabricated proof.

## Architecture

The public site shares the existing Next.js application but has a dedicated marketing component and token layer. Server Components are the default. Interactive code is limited to the beta form; navigation uses native disclosure behavior.

Routes include homepage, Product and module pages, three Solutions pages, Pricing, Resources, About, Contact, Security and legal pages. Resource indexes publish truthful empty states.

## Conversion path

Awareness → understand canonical flow → see control/provenance → identify audience fit → request early access. The request does not create an account or promise admission.

## Responsive and accessible behavior

The content flow stacks vertically without horizontal traps. Mobile navigation uses native keyboard-operable disclosure. Focus remains visible, touch targets are at least 44 px, headings remain ordered and the animated hero has a complete static reduced-motion state.

## Media

The initial Content Constellation is an HTML/CSS product-native prototype. Authentic product video is deferred to the documented capture plan rather than replaced with fabricated footage.
