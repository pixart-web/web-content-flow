# Video Editing Guide

Use direct cuts, restrained 120–320 ms dissolves, subtle 3–6% zooms, product-native easing and short annotation labels. Labels use Geist Mono at a 12–14 px equivalent on a dark translucent surface.

## Delivery

- WebM first, MP4 fallback
- Muted, no autoplay audio
- Hero 24–30 s; features 8–16 s
- Poster and transcript/scene description for every clip
- Preserve readable UI at final display size

## Budgets

- Hero WebM ≤ 4 MB
- Feature WebM ≤ 2 MB
- Hero poster ≤ 250 KB
- Feature poster ≤ 180 KB
- Open Graph image ≤ 400 KB

Document any approved exception with size, reason and measured page impact. Never commit unoptimised raw capture.
