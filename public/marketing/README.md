# Marketing media

The initial website uses product-native HTML, CSS, and SVG compositions. Authentic
product captures must follow `docs/marketing/04-media-production-plan.md`.

Reserved directories:

- `hero/`: hero posters and captures
- `product/`: module illustrations and captures
- `solutions/`: audience-specific compositions
- `backgrounds/`: restrained reusable textures
- `posters/`: video fallback images
- `videos/`: WebM and MP4 product demonstrations

Do not add customer data, fabricated interfaces, generic stock footage, or unoptimised
autoplay media.
