# Screen Capture Guide

## Masters

- Desktop master: 2560×1440
- Delivery: 1920×1080
- Marketing crop: 1600×900
- Tablet: 1024×768
- Mobile: 390×844

Use 100% application zoom, readable UI text, a clean pointer, reduced notifications and the synthetic capture account. Hide bookmarks, profiles, OS chrome, developer tools and local paths.

## Procedure

1. Recreate the isolated database and run the guarded capture seed.
2. Verify “Northstar Roasters” and the MOCK indicator.
3. Disable browser extensions and notifications.
4. Record each storyboard as one calm take plus one backup.
5. Capture stills through `pnpm capture:stills`.
6. Inspect every frame for personal data, tokens, email addresses and local paths.
7. Store raw video outside Git under the restricted production workspace.
8. Commit only optimised delivery files that meet budgets.

Pointer movement must be deliberate. Do not fake typing, loading, job progress or product states.
