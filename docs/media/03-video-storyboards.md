# Product Video Storyboards

No final encoded video is claimed. These storyboards are capture-ready sources for a later editing session.

## Hero — `hero-flow-demo` (27–30 s)

| Time | Screen | Action | Annotation |
|---:|---|---|---|
| 0–4 s | Project Overview → Brief | Calm pointer opens the Brief and pauses on objective/audience | One strategic starting point |
| 4–8 s | Brand Profile | Scroll positioning, voice and message pillars | Shared brand context |
| 8–11 s | Website | Open a structured page and section | Website structure and copy |
| 11–13 s | Social | Show platform and editable post | Adapted, not disconnected |
| 13–15 s | Ads | Show creative angle and headline variants | Campaign-ready concepts |
| 15–17 s | Video | Show hook and scene structure | Structured video direction |
| 17–22 s | Calendar | Filter and review campaign sequence | One visible plan |
| 22–27 s | Library / version / export | Search, open current version, show export | Retained history |
| 27–30 s | Overview resting frame | No cursor movement | One brief. One brand. Every channel. |

## Feature clips

| ID | Duration | Exact flow | Message |
|---|---:|---|---|
| `brief-to-brand` | 12 s | Brief review → Brand Profile summary → version/provenance | Give every channel the same strategic starting point. |
| `website-generation` | 12 s | Website configuration → page → section edit → version | Shape website content from the same brand foundation. |
| `social-studio` | 10 s | Platform filter → content card → edit → version | Adapt the message without losing the brand. |
| `ads-creative` | 10 s | Objective → creative angle → headline/body variants | Move from strategy to campaign-ready concepts. |
| `video-scripts` | 10 s | Objective → hook → scenes → CTA | Turn campaign ideas into structured video concepts. |
| `calendar-planning` | 10 s | Content filters → campaign sequence → manual status | See the campaign as a system. |
| `library-export` | 12 s | Search → item → versions → current → export | Keep every useful version within reach. |

All clips are silent-compatible. Surrounding page content conveys the same meaning.
