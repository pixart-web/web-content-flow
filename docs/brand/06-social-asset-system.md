# Social Asset System

All templates use the Flow Mark, dark canvas, one controlled gradient path, Geist-style typography and a 12-column grid. Recognition should come from layout and flow language, not a large logo.

| Template | Canvas | Content |
|---|---:|---|
| LinkedIn cover | 1584×396 | Proposition, Flow path, compact lockup |
| X cover | 1500×500 | Tagline, constellation crop |
| YouTube cover | 2560×1440 | Safe-zone proposition and product flow |
| Open Graph | 1200×630 | Page title and brand line |
| Square post | 1080×1080 | One insight, one structured visual |
| Portrait post | 1080×1350 | Editorial headline and flow sequence |
| Landscape announcement | 1200×675 | Release fact and product frame |
| Feature card | 1200×900 | One module, one verified capability |
| Quote card | 1080×1080 | Approved editorial quote only |
| Launch card | 1200×630 | Verified launch state only |
| Video thumbnail | 1280×720 | Product frame, short label |

Do not place customer quotes, metrics, awards or logos until evidence and usage rights exist.
