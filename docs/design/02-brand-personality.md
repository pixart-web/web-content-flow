# Brand Personality

## Core traits

- **Intelligent:** anticipates structure and next steps; never performs intelligence theatrically.
- **Confident:** makes clear recommendations and reports state honestly.
- **Efficient:** removes repetition and keeps actions close to content.
- **Organized:** establishes hierarchy across projects, modules, items, and versions.
- **Creative:** opens useful possibilities while respecting constraints.
- **Professional:** supports real delivery work with precise language and dependable behavior.
- **Modern:** uses current interaction patterns with restrained expression.
- **Trustworthy:** preserves work, exposes provenance, and avoids unsupported claims.

## Personality spectrum

| Spectrum | Position | Design consequence |
|---|---|---|
| Serious ↔ Playful | 75% serious | Warmth through helpful copy and color, never jokes in critical states |
| Minimal ↔ Expressive | 65% minimal | Quiet application shell; expression concentrated in marketing and milestones |
| Technical ↔ Human | 40% technical / 60% human | Structured and precise, but framed around user outcomes rather than model settings |
| Premium ↔ Accessible | Balanced, slightly premium | High craft with plain language and familiar controls |
| Bold ↔ Restrained | 40% bold / 60% restrained | Strong hero and primary action; subdued workspace chrome |
| Futuristic ↔ Timeless | 20% futuristic / 80% timeless | Contemporary gradients and motion inside durable layout and typography |

## Emotional outcomes

At key moments users should feel:

- **Starting:** guided, not examined.
- **Generating:** informed, not left waiting.
- **Reviewing:** in control, not overwhelmed.
- **Editing:** safe to experiment, not afraid of losing work.
- **Returning:** oriented, not forced to reconstruct context.
- **Recovering from error:** reassured that completed work remains intact.

## Communication behavior

- Lead with the outcome or state: “Your website copy is ready.”
- Use short explanations that answer “what happened?” and “what next?”
- Call the mechanism “generation” only when state or control requires it.
- Distinguish supplied facts, generated recommendations, and user edits.
- Avoid superlatives, fake certainty, anthropomorphic AI, and technical provider language.

## Visual behavior

- Use strong hierarchy and a calm neutral canvas.
- Use gradient for the brand mark, hero flow, and selected high-value moments.
- Use modular cards aligned to a consistent grid.
- Use icons and labels together for module identity.
- Use motion to clarify continuity and status, never to simulate magic.

## Positive examples

- A Brand Profile card uses a restrained indigo accent, provenance label, and clear “Edit profile” action.
- A generation job progresses through labeled stages with stable dimensions.
- A module empty state explains its output and offers one relevant action.
- A completed pack shows connected module statuses without confetti.

## Anti-patterns

- A pulsing gradient orb presented as the AI.
- “Web Content Flow is thinking…” without job status or recovery information.
- Every card uses a different saturated background.
- Cute mascots in authentication or error states.
- Dense metric tiles that imply analytics outside MVP scope.
